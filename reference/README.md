`course_context/README.md` skrevs 3 september, före synopsisen. Regler, datum, form och inlämningskrav gäller fortfarande. Aktuella datum och personer står i repots [`README.md`](../README.md).

Kursens regel om tidigare uppsatser: bygg inte idén på dem, utgå från forskningsartiklar. Uppsatser som används ska citeras.

Utom i `skrivunderlag_2026-11-20/` finns här bara källmaterialet, inga egna analyser av uppsatserna.
